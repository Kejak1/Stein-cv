1. Berikan nomor rekening **BCA / Mandiri** atau nomor **GoPay / OVO** Anda.
2. Begitu bukti transfer dikirim via WhatsApp, langsung kirimkan file **`GROWTH_OPS_MASTER_DELIVERABLE.md`** (atau link Notion/Google Doc yang berisi isi file tersebut).
3. Jika mereka mengambil jasa setup langsung, minta akses *Editor* ke Google Sheet mereka, copas script dari modul, masukkan link Webhook mereka, dan jalankan *test lead* dalam waktu kurang dari 10 menit.
